# Отчёт: компилятор языка Astra

## Архитектура компилятора

Компилятор реализован как последовательный pipeline из независимых фаз:

```
Исходный код (.astra)
       ↓
   [Lexer]           → поток токенов                  (Lexer::Lexer)
       ↓
   [Parser]          → AST                            (Parser::Parser)
       ↓
  [Semantic]         → аннотированный AST             (Semantic::Analyzer)
       ↓
   [Codegen]         → x86-64 NASM                    (Codegen::Generator)
       ↓
  [nasm + cc]        → исполняемый файл
```

Каждая фаза реализована в отдельном модуле в соответствующем namespace. Смешивания фаз нет.

## Принятые проектные решения

### Лексер
Ручной однопроходный лексер без использования регулярных выражений или генераторов. Токены хранят тип, лексему и позицию (строка, столбец).

### Парсер
Метод: **рекурсивный спуск** с Pratt parsing для выражений (корректный учёт приоритетов и ассоциативности операторов).

**Обработка ошибок без исключений**: диагностики накапливаются в `std::vector<Diagnostic>`. Флаг `panicMode_` подавляет каскадные ошибки. При включённом `recoverErrors` парсер синхронизируется (пропускает токены до следующей конструкции) и продолжает разбор. Исключения в парсере **не используются** — это соответствует требованиям ТЗ.

### Семантика
Двухпроходный анализ: сначала регистрируются все объявления (типы, функции), затем анализируются тела функций. Используется цепочка областей видимости (`Scope*`) с лексическим разрешением имён. Каждый узел AST помечается каноническим именем типа в поле `semanticType`.

### Кодогенератор
**Нативная генерация x86-64 NASM** под **System V AMD64 ABI**. Прямой backend от аннотированного AST; промежуточное представление (IR) не используется — это допустимое упрощение для учебного проекта.

Ключевые аспекты реализации:
- все локальные переменные — фиксированные смещения от `RBP`
- агрегатные типы (массивы, структуры) хранятся inline на стеке и копируются побайтово
- функции, возвращающие агрегаты, получают скрытый первый аргумент `rdi` — адрес буфера результата (соответствует System V ABI для больших возвращаемых значений)
- деление на ноль и выход за границы массива: runtime-проверка с вызовом `astra_rt_div_zero` / `astra_rt_oob`
- `float32`/`float64` обрабатываются через XMM-регистры (`movss`/`movsd`, `addss`/`addsd` и т.д.)
- сравнение агрегатов (`==`/`!=`): покомпонентное — по элементам для массивов, по полям для структур
- поддержка всех типов: int8..int64, uint8..uint64, float32, float64, bool, string, массивы, структуры

## Дополнительные возможности

- **Вывод типов** для `let`-переменных (одношаговый, по типу инициализатора)
- **`--emit-asm`** — вывод только ассемблерного файла без линковки
- **`--dump-ast`** — вывод AST после парсинга (до семантики) для отладки
- **`--dump-tokens`** — вывод потока токенов для отладки лексера

## Известные ограничения

1. Функция `print` не поддерживает структуры и массивы (только скалярные типы и строки)
2. Строки реализованы как `char*` через runtime-библиотеку (`astra_string_concat`, `astra_string_eq` и др.)
3. Не более 6 целочисленных и 8 float-аргументов у функций (ограничение регистрового ABI)

## Тестовые программы

Тесты находятся в `examples/tests/`:

| Файл | Что проверяет |
|------|---------------|
| `basic.astra` | функции, if/else, while, арифметика |
| `arrays.astra` | литерал массива, индексирование, присваивание элементу |
| `structs.astra` | литерал структуры, доступ к полю, присваивание полю |
| `floats.astra` | `float64`, арифметика через XMM |
| `casts.astra` | явное приведение типов (`as`) |
| `oob.astra` | runtime bounds check при выходе за границы массива |

## Инструкция по сборке

```bash
mkdir build && cd build
cmake ..
cmake --build . -j
```

Или без cmake (из директории `src/`):

```bash
g++ -std=c++23 -o astra lexer.cpp parser.cpp semantic.cpp ast_dump.cpp codegen.cpp main.cpp \
    -DASTRA_RUNTIME_C_PATH='"./runtime.c"'
```

## Запуск тестов

```bash
./build/src/astra examples/tests/basic.astra   -o build/basic   && ./build/basic
./build/src/astra examples/tests/arrays.astra  -o build/arrays  && ./build/arrays
./build/src/astra examples/tests/structs.astra -o build/structs && ./build/structs
./build/src/astra examples/tests/floats.astra  -o build/floats  && ./build/floats
./build/src/astra examples/tests/casts.astra   -o build/casts   && ./build/casts
./build/src/astra examples/tests/oob.astra     -o build/oob     && ./build/oob
```

## Инструмент сборки и стандарт

CMake 3.20+, C++23, поддерживаются `g++` и `clang++`.
